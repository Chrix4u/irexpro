one-to-one greedy nearest-first matching within tolerance; surplus events near an already-claimed point are counted as repeated observations, not true positives; events with no point in tolerance are false alarms; latency = event bar minus ground-truth bar (negative = fired early). Negative latency = the event fired before the planted reversal. Repeated observations of an already-matched reversal are counted as repeated, NOT as new true positives; precision counts them as detections that failed to produce a new match.

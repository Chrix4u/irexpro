# TradingView → iRexPro PAPER evidence

Provider evidence key: **`tradingview-six-pair-v1`**.

Status: **PAPER evidence collection only.** This integration does not grant DEMO or LIVE authority.

## Webhook URL

`https://irexpro.lightworldtech.com/api/v1/ai/external/tradingview`

The alert message must not contain an iRexPro password, broker credential, API token, user ID, session ID, or broker connection ID. Those bindings are resolved server-side.

## TradingView setup

1. Open TradingView Pine Editor and paste `scripts/tradingview/irexpro-six-pair-paper-evidence.pine`.
2. Save it and add it to a chart. For the initial run, use a **5-minute chart** and leave **Signal timeframe = 5**.
3. Verify the six source symbols. Defaults use OANDA majors; replace only the TradingView data source if required. The iRexPro instrument names remain EURUSD, GBPUSD, USDJPY, AUDUSD, USDCAD, USDCHF.
4. Create one alert on the script.
5. Condition: **Any alert() function call**.
6. Webhook URL: use the URL above.
7. Do not replace the dynamic message generated by the script with credentials or secrets.
8. Leave the active iRexPro account in **PAPER_ONLY** mode while evidence is being collected.

## What the collector sends

The collector ranks all six majors and emits at most one candidate per selected signal bar. The payload includes instrument, BUY/SELL direction, confidence, reference price, ATR-based stop/target, timeframe, regime, volatility score, generated time, expiry, and a deterministic event id.

The TradingView rule is intentionally simple and **is not treated as a proven edge**. It exists to populate iRexPro's provider scorecard with real independent PAPER evidence. iRexPro still performs server-side:

- source verification and replay/idempotency protection;
- >=60% confidence enforcement;
- exact PAPER session/broker authority binding;
- position sizing and capital allocation;
- Risk Engine checks;
- market-safety checks;
- execution and realised P&L tracking;
- provider qualification metrics.

A provider remains PAPER evidence only until it has enough closed trades and every iRexPro promotion gate passes. Even then, the current integration only becomes eligible for a separate DEMO review; it does not auto-promote.
